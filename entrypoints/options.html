SCREENPULSE

Set up automatic capture

ScreenPulse saves private screenshots of the visible active Chrome webpage. Chrome labels the required permission as access to all sites, but ScreenPulse only captures visible HTTP/HTTPS webpages. It never captures your desktop, Incognito windows, Chrome internal pages, or full webpages.

Captures occur every 30 minutes, using this computer’s local time. The end time is not captured.

Upload screenshots

Images are saved locally first. Add your endpoint and revocable device token to upload each new capture immediately.
